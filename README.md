# GAMAD Template — Node.js API

Template de référence GAMAD pour une API Node.js. Déployez sur votre VPS en quelques clics depuis [deploy.gamad.net](https://deploy.gamad.net).

## Variables

| Variable | Requis | Description |
|---|---|---|
| NODE_ENV | ✅ | Environnement (production) |
| PORT | ❌ | Port (défaut 3000) |
| DATABASE_URL | ❌ | URL PostgreSQL |
